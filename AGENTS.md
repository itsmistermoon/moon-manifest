# AGENTS.md — moon-manifest

Portfolio de Juan Pablo Armstrong en Astro y Tailwind CSS, desplegado automáticamente en Vercel desde `main`: `https://jparmstrong.vercel.app/`.

## Instrucciones

- Las reglas generales y la metodología viven en el repo central `moonbase` (`~/moonbase/AGENTS.md`).
- Lee `.hot/HANDOFF.md` si existe.

## Reglas específicas

- Deploy: `git push origin main` → Vercel CI/CD. No hagas deploys manuales.
- Respeta la identidad visual; cambios de diseño requieren confirmación de moon.
- Issues: GitHub Issues en `itsmistermoon/moon-manifest`. Ver `docs/agents/issue-tracker.md`.
- Triage: roles canónicos por defecto. Ver `docs/agents/triage-labels.md`.
- Domain docs: contexto único. Ver `docs/agents/domain.md`.
