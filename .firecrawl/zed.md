## Design System Overview

The **Zed** design system captures the visual language of a well-known design and creative tools product. This DESIGN.md file distills its color palette, typography, spacing scale, and component patterns into a format that AI coding agents can read and follow when generating UI.

High-performance code editor. Minimal, dark, fast.

AI agents like Cursor, Claude Code, Codex, and Google Stitch can reference this file to produce UI that visually matches the **Zed** aesthetic — consistent colors, proportional spacing, and recognizable component patterns — without requiring explicit pixel-by-pixel instructions for every element.

## Use with AI Coding Agents

Copy one of these prompts into your AI coding agent to apply the Zed design system to your project. The DESIGN.md file in your repo root is the source of truth.

Cursor / .cursor/rulesClaude Code / CLAUDE.mdCodex

```
# .cursor/rules (or DESIGN.md)
You are working in a project that uses the Zed design system.

Read the DESIGN.md file in this project root and follow it strictly when generating UI.
Match the brand's exact colors, typography, spacing scale, and border radius.
Do not create generic Tailwind UI — apply the visual language from DESIGN.md.

Key rules:
- Use the defined color palette, not arbitrary hex values
- Apply the correct font family and weight scale
- Follow spacing tokens (4/8/12/16/24/32px scale)
- Match component patterns: buttons, cards, inputs, badges as specified
```
